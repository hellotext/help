# Repository instructions

Use English for Git branch names, commit messages, and pull request titles and descriptions.

Before committing, keep only the code required for the final working solution. Do not add tests for database migrations or CSS and stylesheets; verify styling in the browser.

Before editorial article, screenshot, or message-preview work, initialize the `docs/editorial` submodule and read `docs/editorial/skills/hellotext-editorial/SKILL.md`. Follow the linked shared rules and `docs/editorial-integration.md` for Help-specific paths, rendering, and publication. Do not maintain a second copy of the shared rules.
