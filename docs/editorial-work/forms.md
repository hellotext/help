| Button | The form preview shows the action label beside the field. Its inline text toolbar duplicates the heading control and obscures the button; omit a second figure. |
| Notice | The form preview shows complete SMS-matched consent directly below the button. Its inline text toolbar obscures the notice and adds no distinct control; omit a second figure. |
| Optional coupon and journey | Screenshot only after an inert form draft can be created under exact DB, business and account guards. Show complete selectors with `None selected` if no safe fictitious coupon/journey exists; never imply delivery. If the panel is empty or misleading, retain visual debt. |
| Hosted link and embed | The hosted link card contains the local `127.0.0.1` fixture URL, which would be misleading to copy from a public guide; omit that figure and explain the product's generated link in prose. The separate embed card shows the actual HTML structure and fictional form identifier without a misleading public URL. |
| Verification, testing, troubleshooting and JavaScript events | These explain behavior or checks outside a single stable UI control. No screenshot of a real opt-in, verification message or successful delivery; prose and precise links are more useful and avoid fabricated outcomes. |
