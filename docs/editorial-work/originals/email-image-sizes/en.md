Emails are 640 px wide by default. Upload each image at twice the size it is displayed, so it stays sharp on phones and high-density screens. The height is up to you: the email keeps the proportions of your image and never crops it.

## Recommended sizes

These sizes assume the default email width of 640 px.

| Use | Displayed at | Upload at (2×) |
| --- | --- | --- |
| Full-width image | 640 px | 1280 px wide |
| Image at 50% width | 320 px | 640 px wide |
| Two equal columns | 320 px each | 640 px wide each |
| Three equal columns | About 213 px each | About 426 px wide each |

Inside a table, the width of each image depends on its column, so size the image for the column and not for the whole email.

## File requirements

- **Formats:** PNG, JPG, GIF, or WebP.
- **Size:** up to 5 MB per image. Lighter images make the email open faster.

## If you change the email width

The email width can be set between 320 and 1200 px in the theme. A full-width image is as wide as the email, so upload it at twice that width. An image that fills half the width or one column needs twice its own displayed width, not twice the email width.
