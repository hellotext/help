Las notificaciones del navegador ayudan a los integrantes a detectar trabajo nuevo de clientes incluso cuando no están mirando el Inbox.

El acceso a las notificaciones se configura para cada navegador y dispositivo. Activarlo en una computadora no lo activa automáticamente en otra computadora, perfil de navegador o teléfono.

## Qué puede generar una notificación

Hellotext puede notificar a un integrante cuando:

- Un cliente envía un mensaje nuevo en una conversación asignada a ese integrante.
- Otro integrante o un agente de IA le asigna una conversación.
- Alguien lo menciona en una nota interna.
- Un cliente envía un mensaje nuevo en una conversación sin asignar.

En una conversación asignada, la notificación del mensaje entrante se dirige al integrante responsable.

En una conversación sin asignar, la notificación del mensaje entrante puede llegar a los usuarios del negocio que tengan notificaciones activadas en sus dispositivos. Asignar las conversaciones rápidamente ayuda a reducir alertas generales y deja claro quién debe responder.

Las respuestas automáticas y los comandos de desuscripción del cliente no generan la notificación habitual de mensaje entrante.

## Activa las notificaciones en un dispositivo

1. Abre el menú de tu avatar en Hellotext.
2. Selecciona **Ajustes de Cuenta**.
3. Busca **Notificaciones push**.
4. Selecciona **Activar**.
5. Cuando el navegador solicite permiso, selecciona **Permitir**.

Hellotext confirma que las notificaciones push están activadas en el dispositivo actual.

Repite estos pasos en cada navegador y dispositivo donde quieras recibir notificaciones.

## Qué sucede cuando llega una notificación

El navegador o sistema operativo muestra la notificación de acuerdo con sus propios ajustes.

Selecciona la notificación para abrir o enfocar la conversación correspondiente en Hellotext. Si Hellotext ya está abierto en esa conversación, el navegador puede evitar una alerta duplicada.

Cuando Hellotext está abierto, también puede reproducir el sonido de notificación del Inbox. El navegador puede impedir el sonido hasta que hayas interactuado con la página, y se siguen aplicando el volumen y los modos de concentración del sistema operativo.

Hellotext no ofrece actualmente un control separado para el sonido. Este depende de la suscripción del navegador, sus reglas de audio, el volumen del dispositivo y los ajustes de notificaciones del sistema operativo.

## Desactiva las notificaciones en un dispositivo

1. Abre el menú de tu avatar.
2. Selecciona **Ajustes de Cuenta**.
3. Busca **Notificaciones push**.
4. Selecciona **Desactivar**.

Esto elimina la suscripción activa del navegador actual. No desactiva las suscripciones que habilitaste en otros navegadores o dispositivos.

## Si bloqueaste el permiso del navegador

Después de seleccionar **Bloquear** o rechazar el permiso, es posible que el navegador no permita que Hellotext vuelva a solicitarlo.

Abre los permisos del sitio para Hellotext en el navegador, cambia Notificaciones a **Permitir** y recarga Hellotext. Después, vuelve a **Ajustes de Cuenta** y activa nuevamente las notificaciones push.

Si el navegador no admite notificaciones web push, Hellotext no puede activarlas allí. Usa un navegador actualizado y compatible u otro dispositivo.

## Si están activadas pero no aparecen

Revisa:

- Las notificaciones están activadas en Hellotext para este navegador y dispositivo exactos.
- El navegador permite notificaciones para Hellotext.
- El sistema operativo permite las notificaciones del navegador.
- Los modos de concentración, No molestar o ahorro de batería no están ocultando las alertas.
- Iniciaste sesión con la cuenta y negocio correctos de Hellotext.
- La conversación está asignada a ti, te menciona o se encuentra sin asignar cuando llega el mensaje del cliente.
- El perfil del navegador no eliminó los datos del sitio ni la suscripción push.

Desactiva y vuelve a activar las notificaciones desde **Ajustes de Cuenta** si el permiso del navegador está habilitado pero la suscripción ya no aparece activa.

## Si aparece la notificación pero no suena

Revisa:

- El dispositivo y el navegador no están silenciados.
- Interactuaste al menos una vez con la pestaña del navegador para que pueda reproducir audio.
- El sistema operativo permite sonido para las notificaciones del navegador.
- El modo de concentración o No molestar no está silenciando las notificaciones.

La notificación visual y el sonido están controlados por varias reglas del navegador y el sistema operativo. Recibir uno no garantiza que el otro esté permitido.

## Mantén útil la responsabilidad de las notificaciones

Las notificaciones funcionan mejor cuando el responsable de cada conversación está actualizado.

- Asigna el trabajo activo al integrante responsable de la próxima respuesta.
- Usa menciones cuando necesites contexto o una decisión sin transferir la responsabilidad.
- Revisa las conversaciones sin asignar para que los mensajes nuevos no continúen como alertas generales del equipo.
- Cierra el trabajo completado y usa recordatorios para conversaciones que deban regresar más adelante.

Usa [Filtra y busca conversaciones en el Inbox]({% link _team/filter-and-search-inbox.md %}) para encontrar la cola correspondiente después de abrir Hellotext.
